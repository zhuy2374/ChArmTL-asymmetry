# ChArmTL Analysis and Parental-Origin Assignment Workflow

This workflow supports the processing and analysis of Chromosome-arm-specific telomere lengths (ChArmTLs) data generated with Telogator2, from batch processing and multi-sample result integration to quality control, parental-origin assignment, and downstream statistical analysis.

A key component of the workflow is the inference of the parental origin of offspring ChArmTLs by comparing telomere variant repeat (TVR) sequence similarity between offspring and parental samples. The inferred assignments are subsequently reviewed manually and incorporated into the QC-passed dataset for parent-of-origin analyses.

### Workflow Overview

The workflow consists of four major stages:

1. **Telogator2 processing and result integration**  
Batch processing with Telogator2 and integration of sample-level outputs into a unified dataset.
2. **Parental-origin assignment**  
Inferring the parental origin of offspring ChArmTLs based on TVR sequence similarity between offspring and parental samples.
3. **Quality control and ChArmTL characterization**  
QC and filtering of the merged Telogator2 dataset, followed by basic characterization of ChArmTLs.
4. **Parent-of-origin analysis and independent validation**  
Comparison of paternal and maternal ChArmTLs and independent validation using the CEPH-1463 family dataset.

### Repository Structure

#### run_telogator2

Shell scripts for batch execution of Telogator2 and integration of results generated across multiple samples.

* **`batch_telogator2_jobs.sh`**  
Automates batch processing of a cohort by iterating through a sample list and dynamically generating individual Slurm submission scripts for each sample.

* **`merge_telogator2_results.sh`**  
Aggregates the resulting `tlens_by_allele.tsv` files generated by individual Telogator2 runs into a unified TSV file.

#### tools/similarity_compute

`similarity_compute` is a Python-based tool developed to infer the parental origin of offspring ChArmTLs by quantifying TVR sequence similarity between offspring and parental samples using Telogator2-derived telomere sequence information. 

`similarity_compute` is maintained as an independent Python project, with its own `pyproject.toml` and `uv.lock`.

For installation, usage, input/output requirements, and command-line options, please refer to the dedicated documentation:  
[`tools/similarity_compute/README.md`](https://github.com/zhuy2374/ChArmTL-asymmetry/blob/main/tools/similarity_compute)

#### downstream_analysis

R scripts for data QC, descriptive analysis, statistical testing, and visualization of ChArmTLs.

* **`01_qc_and_filtering.R`**  
Performs essential quality control and filtering on the raw merged data.

    >**Note:** Parental-origin assignments are generated separately using [`tools/similarity_compute`](https://github.com/zhuy2374/ChArmTL-asymmetry/blob/main/tools/similarity_compute). The resulting assignments are manually reviewed and then merged with the QC-passed ChArmTL dataset generated by this script.

* **`02_post_qc_summary.R`**  
Generates summary statistics and visualizations to characterize the ChArmTL dataset after quality control and filtering.

* **`03_sex_age_and_ranking_conservation.R`**  
Evaluates sex- and age-related variation in ChArmTLs and assesses the conservation of CharmTL ranking.

* **`04_parental_origin_comparison.R`**  
Evaluates differences in ChArmTLs between paternal and maternal haplotypes within offspring. Statistical tests and visualization are used to assess potential parent-of-origin effects on telomere lengths.

* **`05_validation_in_CEPH-1463.R`**  
Performs an independent validation analysis using the classic CEPH 1463 family dataset to assess the reproducibility and generalizability of the ChArmTL parental-origin analysis.
